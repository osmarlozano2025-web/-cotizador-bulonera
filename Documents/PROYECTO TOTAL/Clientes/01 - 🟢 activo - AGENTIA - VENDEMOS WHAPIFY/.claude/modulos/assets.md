# Modulo assets

Este modulo describe como se ordenan los archivos visuales del proyecto.

## Carpetas

| Carpeta | Uso |
| --- | --- |
| `01 - marca` | Logos, perfiles, identidad visual y piezas base de marca. |
| `02 - creativos` | Creativos publicitarios o piezas graficas generales. |
| `03 - redes-sociales` | Portadas, publicaciones o piezas especificas para redes. |
| `99 - pendientes-clasificar` | Archivos que todavia no tienen uso claro por el nombre. |

## Criterio

Los archivos se clasifican por nombre visible.
Si el nombre no alcanza para entender el uso, se deja en pendientes para revisarlo mas adelante.
